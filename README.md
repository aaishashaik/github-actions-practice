# GitHub Actions Practice

Practice workflows I built while learning CI/CD with GitHub Actions.

## Workflows
- 01-needs-examples: running jobs in order using `needs`
- 02-job-outputs: passing data from one job to another
- 03-inputs: workflows that accept inputs
- 04-multiple-runners: running jobs on different runners
- 05-branch-pr: triggering workflows on branches and pull requests
- 06-manual-trigger: starting a workflow manually

## Tools
GitHub Actions, YAML, Git, GitHub
